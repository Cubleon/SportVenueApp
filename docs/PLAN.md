# План SportVenue до выпуска

Единый план работ. Идём по этапам сверху вниз. Пункт отмечается `[x]` только
когда он сделан и проверен (для кода — зелёные проверки GitHub). Новые задачи
дописываются в нужный этап, а не держатся в голове.

**Обновлено:** 31 октября 2026, этап 1 закрыт.

**Кто делает:** **К** — Claude (код, тесты, документы) · **В** — владелец ·
**С** — разработчик сервера · **Ю** — юрист / бухгалтер.

**Ограничение по деньгам:** брать деньги с игроков можно только после
открытия ИП и подключения оплаты (ориентир — январь 2027). До этого —
только тестовые оплаты.

## Этап 1. Клиент: что можно сделать без сервера и без решений

- [x] **К** Тёмная тема: все 18 экранов пройдены, серьёзных проблем нет.
- [x] **К** Крупный системный шрифт (×1,3 и ×1,6): карточка клуба на главной
      перестраивается (цена под плашками), названия и плитки в две строки,
      подписи в карточках брони/игры занимают до половины ширины.
- [x] **К** Доступность: тест — у всех нажимаемых элементов есть подпись для
      чтения с экрана и размер не меньше 44×44 (5 экранов × 2 темы).
- Пуш-уведомления, сбор падений и аналитика и контакт поддержки перенесены:
  без ключей и решений владельца это был бы мёртвый код (см. этапы 2 и 3).

## Этап 3. Сервер и связка (вместе с разработчиком сервера)

- [ ] **С** Тестовый сервер с адресом, доступный для проверки.
- [ ] **К** Сборка клиента под тестовый сервер; прогон всего пути на живых
      данных: вход → бронь → доли → оплата → отмена → возврат → заявки.
- [ ] **К** Проверка состояния «сервер не отвечает» на всех экранах.
- [ ] **С** Сервер расположен в России (152-ФЗ, локализация данных).
- [ ] **С** Резервные копии базы и слежение за работой сервера.
- [ ] **С** Эндпоинты из раздела «Добавлено 30 октября» документа API
      (ссылки, заявки, отмена игры, по желанию `PATCH /games/{id}`).
- [ ] **С + К** Уведомления: сервер отправляет (заявка одобрена, игру
      отменили, срок оплаты, возврат), клиент запрашивает разрешение,
      показывает список под колокольчиком и открывает нужный экран по нажатию.
- [ ] **К** Обновлять документ API при каждом изменении клиента.

      / волейбол из открытых данных.
- [ ] **Ю** Проверить, можно ли использовать данные 2ГИС в своей базе и на
      своей карте. Если нельзя — брать из OpenStreetMap и data.mos.ru.
- [ ] **В** Договориться с первыми 5–10 клубами: цены, расписание, правила

- [ ] **С** Загрузка каталога клубов на сервер.
